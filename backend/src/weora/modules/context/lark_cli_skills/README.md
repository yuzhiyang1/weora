# 官方飞书 CLI Skills

本目录保存官方 `larksuite/cli` 的 `skills/` 和 MIT 许可证。来源为 [v1.0.80](https://github.com/larksuite/cli/tree/v1.0.80/skills)，提交为 `29a97dbde8d2bef4f87145a68869ae04f75a0fd4`，与 Weora Worker 使用的 CLI 版本对齐。

27 个 Skill 的入口、参考文件、模板和脚本按上游目录完整保留。更新 CLI 时，从对应标签重新导出完整 `skills/` 与 `LICENSE`。

启用 Agent 飞书 CLI 后，可通过 `lark.cli.skill` 查阅入口和 Markdown 参考文件，再通过 `lark.cli.exec` 用当前已绑定的 Bot 执行命令。上游脚本和模板随项目保存，供维护者查阅。
