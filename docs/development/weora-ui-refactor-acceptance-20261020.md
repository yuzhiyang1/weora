## 自动检查

在仓库根目录执行：

```powershell
pnpm --filter @weora/web typecheck
pnpm --filter @weora/web lint
pnpm --filter @weora/web build
pnpm --filter @weora/web exec vitest run --reporter=json --outputFile=../../output/ui-refactor-tests.json
```

类型检查、Lint、生产构建均通过。前端测试 76/76 通过，包含原有权限撤销、审批、仓库选择及渠道契约用例。新增覆盖控件行为、快捷查找、外观切换、概览真实统计、部分请求失败、任务筛选和 Skill 弹窗重开。Vitest 限制为四个 worker，避免 Windows 下并行 JSDOM 的资源争用。
