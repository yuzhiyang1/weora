## 设计依据与修改

公开来源：[HeroUI Design Taste](https://heroui.pro/docs/react/getting-started/design-taste)。公开页提供十类方向；项目的 `references/design-taste.md` 是据此编写的 Weora 规则，不是未获取的完整 78 条规则。

- Skill 入口、设计契约、UI 元数据与 ADR-0013 已关联该参考；后续页面工作需读取并应用。
- 工作台移除宣传区和装饰流程，使用 HeroUI Card 的 Header / Title / Content / Footer 呈现指标、真实任务和待处理事项。侧栏快捷操作降为 secondary，页面保留明确的主操作。
- 共享页面、侧栏、表单、认证及代码设置的过小字号已提高；正文和标签以 14px、辅助文字以 12px 为基线。工作台间距使用 spacing 标尺，保留官方默认表面、圆角和阴影。
- Router 链接增加可见的键盘焦点；共享页签保持单行。运行详情网格允许列收缩，宽页签在 HeroUI 自身容器滚动，窄屏详情卡使用 16px 内边距。
- 待处理任务查询未完成或失败时数量为“—”，未知状态不显示绿色成功图标；任务失败状态引导进入任务列表重试。Agent 查询失败给出恢复说明，不误报为没有发布版本。
