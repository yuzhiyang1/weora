## 已修复的代码问题

- 个人资料保存复用身份 API 的错误映射与 CSRF 处理；AuthProvider 直接应用保存响应，不再依赖第二次 GET。头像处理期间也纳入草稿保护。
- 模型两份草稿共享服务器版本基线：预算保存不发送未保存的连接或 Key，连接保存沿用刚返回的新版本；成功后只更新对应草稿，服务端 CAS 与不可变版本保持不变。
- 模型探测按块读取有上限的完整响应，避免第一次网络读取只收到部分 JSON 时误报连接失败；仍固定官方地址、禁止重定向、不发生成请求。
- 公开设置投影不解密密钥。旧加密密钥失效时，管理员可以读取配置并轮换；执行和探测仍严格解密，旧运行不能静默回退到新密钥。
- 设置应用服务改为依赖领域层 `SettingsRepository` 协议；SQL 事务和 CAS 留在持久化适配器，DTO 不再从 SQL 实现反向导入。
- 设置中的模型、Git、协调及仓库读取错误时，不把已有缓存继续呈现为可正常编辑的新结果。
