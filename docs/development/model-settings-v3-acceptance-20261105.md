## 空预算的语义与版本保护

三个字段可逐项留空。Web 提交 `null`，API 保存后原样返回，刷新仍为空；显式填写时继续要求正整数并校验各自上限。空值不是零，也不会关闭超时保护。

保存预算时将空项解析为部署默认值，并把实际整数预算一起冻结到同一个目录版本的 `effective_*` 字段。读取目录增加 `effective_budget`。切换 Key、改名、后续部署默认值变化，都不重新解析已经保存的预算；再次保存预算才采用新的部署默认值。历史任务及续接继续使用旧版本。原目录的整数预算与原单配置 API 保持兼容，不增加表或 DDL。

并发保护同时比较草稿的原始输入与实际预算；即使两个配置的输入同为空，实际默认值发生变化也会使用原版本提交并由 CAS 拒绝覆盖。新增此行为的前后端回归。
