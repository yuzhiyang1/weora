## 报告内容与边界

- `RunReport` 只展示持久化的 `output_text`，不重新总结或改写事实。
- `MarkdownContent` 使用 react-markdown 和 GFM 渲染标题、列表、表格、链接与代码。
- 原始 HTML 按文字处理；危险链接被移除，外链新窗口隔离。模型生成的图片地址不会自动请求，截图沿用现有产物鉴权预览。
- 三列及以上的宽表仅在自身区域横向滚动；原文和展开后的任务指令保留完整文本。
- 工具调用参数、JSON、日志和差异继续以原文展示，避免格式渲染改变证据含义。
- 飞书的简短原生图文回复独立于控制台的完整报告，本次不修改其发送协议。

设计、实现与浏览器检查截图放在被 Git 忽略的 `output/`；不把真实账号、密钥或本地验收资料写入设计说明或提交内容。
