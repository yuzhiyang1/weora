# ADR 0021 会话审计日志与模型窗口分别限额

2026-11-07 采纳。登录态浏览器联调暴露了两种独立的传输限制。完整检查点被反复计入新增输出总量，持续主会话也会因历史累计而超过单次请求限制。

平台继续保存完整会话日志。每次恢复时，模型读取最近 96 KB 内的完整运行轮次，运行入口以 `weoraInputIds` 标记。单条插话不能成为裁剪边界，避免丢失其关联工具调用。缺少边界标签的大型旧日志从本轮已授权事实重新读取，原日志继续留在持久记录中。

子进程检查点只携带模型窗口及新增内容。父进程在调用持久化回调前补回保留的审计前缀。成员、消息保留期、工具租约、模型配置和审批继续由现有应用服务复核。

单个运输帧仍最多 300 KB。完整检查点每轮最多 256 帧，覆盖最多 64 次工具调用的正常检查点频率；父进程、工具网关与 Runtime 使用一致的工具预算。其他输出继续使用 2 MB 总量限制。单次模型请求及子进程上下文限制继续生效。
