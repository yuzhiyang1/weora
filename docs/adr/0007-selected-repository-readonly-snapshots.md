# ADR 0007 选中仓库的连接校验、固定提交与只读工具

- 状态：Accepted。
- 日期：2026-10-20。
- 承接：[ADR 0006](0006-projects-and-selected-repository-context.md)。

## 决策与责任

开发者仍自行维护项目及多个仓库。本切片将登记资料扩展为可验证的只读代码来源，不启用跨仓写入或远端交付。

平台负责认证、凭据代理、受限网络、默认分支解析、固定提交物化和持久状态。Agent 根据任务决定是否读代码、读取哪个已选仓库的文件及如何解释结果；`repo.file.read(repository_id, path)` 负责受控读取并返回仓库 ID、提交、内容与 SHA-256。平台准备成功不等于 Agent 已读，模型自述不替代 Tool 事实。

`RepositoryReader` 是 Projects 的应用端口，`GitRepositoryReader` 是 Git 对象适配器；Runs 只通过 `ProjectContextCatalog` 协作，不直接读取项目表或密钥。Git 获取不依赖 Codeup/GitLab API；创建评审请求继续由 ADR 0004 的独立适配器处理。

## HTTPS 用户名与密码

私有 HTTPS 使用开发者明确填写的 Git 认证用户名和 Git 密码或访问令牌，均按 HTTP Basic 密码位原样传递，不根据字符串格式强制 PAT。这里使用代码托管服务接受的 Git 认证信息，不推断网页登录凭据可用于 Git。

为兼容既有客户端，API 写入字段仍叫 `credential_token`，并非仅支持令牌。秘密使用平台加密服务存储，仅后台短时解密；不放进 URL、进程参数、仓库配置、模型输入或普通响应。未传/null 保留，空字符串明确清除。换地址清除旧秘密，不能把原凭据自动发给新目标。

## 连接与快照

1. 保存资料不联网；管理员或项目创建者可显式校验默认分支可读性，记录时间、连接版本、提交或安全错误码。
2. 新任务冻结选中仓库的连接版本。首次调用读取工具时，仅为目标仓库绑定固定提交。后台同步模式使用已就绪的本地提交，旧模式解析默认分支并拉取固定提交。
3. 仓库首次被请求后，以 Run、仓库为联合键保存 `PREPARING / READY / FAILED`、提交与错误码。分支解析失败时提交为空；已有固定提交的恢复只拉取原提交。并发固定提交和完成采用 CAS，落后克隆只清理自己的 UUID 目录。
4. `git init --bare` 加固定提交的浅 fetch，不 checkout，不下载 LFS，不执行脚本、hook、filter 或子模块。
5. 工具必须显式提供本次选中的仓库 ID；缺少 ID、超出选仓范围、仓库停用或连接版本变化时拒绝，不回退旧 W02 默认仓库。
6. 选仓限定访问范围，启动任务不准备仓库。准备失败同时记录到该仓库和工具调用，由 Agent 继续处理可用资料并说明缺失的证据。研发提案仍须绑定已准备的固定提交，沙箱物化须等待审批。

只有部署配置了缓存目录的新任务才带 `git-objects-v1` 协议。旧资料型任务不会自动获得网络或读代码能力；无项目任务保留原有兼容行为。按需准备受工具时限、Run 租约、取消和总运行时限保护。

## 网络、存储与权限

Git 子进程使用环境白名单，隔离个人配置、credential helper、代理、Git Trace 与 SSH agent。默认只允许公开地址的标准 HTTPS/SSH 端口，DNS 检查后固定连接地址；禁止 HTTP 重定向并保留 TLS 校验。内网 GitLab、私有 CA 或特殊端口只能由部署管理员登记精确 origin 和证书，不能由模型覆盖。

云效真实验证发现官方仓库网页地址（无 `.git`）返回跨站 302，而同仓 `.git` 地址返回 Git 协议数据。因此仅对 `https://codeup.aliyun.com` 做确定性的 `.git` 地址规范化，不跟随跳转、不推测其他平台规则。读边界兼容旧登记，认证 Header 与 Git 参数始终使用同一规范地址；等价规范化不清除旧密码、不推进连接版本，且在项目聚合锁内按规范地址判重。真实更换仓库仍清除旧凭据。

SSH 必须使用管理员为该工作空间/仓库配置的专用密钥和 known_hosts，强制主机校验；本轮没有完成真实 SSH 服务验收。

裸库按 UUID 分目录，拒绝缓存路径越界；文件从对象数据库读取，最多 64 KiB UTF-8 普通文本，拒绝敏感路径、符号链接、子模块及目录。Git 过程有超时及每库克隆大小监测。该监测不是硬资源沙箱；全局配额、缓存保留期限和崩溃孤儿清理仍待后续治理，不能声称已具备生产级缓存生命周期。

读取前后重验项目、仓库、连接版本和成员授权；最终模型输出继续走既有撤权检查。Run 详情 API 先核验私有任务可见性，再返回不含宿主路径或凭据的准备状态。

## 验收与范围

参见 [只读接入验收记录](../development/weora-repository-readonly-acceptance-20261020.md)。真实本机 HTTPS Git 服务验证认证、固定提交及只读工具；真实云效用户仓库必须另有成功证据，不能用本机夹具代替。

未授权或未实现：动态多仓改码、跨仓原子提交、推送、MR/PR 创建、合并、部署。Git 协议可替换不代表托管平台评审 API 相同。
