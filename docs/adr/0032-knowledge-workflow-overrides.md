# 0032 团队知识工作流覆盖

- 状态：Proposed
- 日期：2026-11-21

参考 TeamAI CLI `1104f305` 的 `workflows/teamai-share-learnings.yaml` 和 `docs/guide/zh-CN/workflow.md`。团队能够修改知识流程的描述、发起策略、草拟步骤、依赖和审批。成员按生效定义启动，审核同一份拟发布内容。

Weora 在工作空间范围保存管理员上传的覆盖和恢复默认记录。每次修改追加版本和变更人。覆盖需要携带读取到的基准版本。运行计划绑定具体版本和发起项目。会话经验分享有归档或评分选项时，也冻结会话分享子流程的版本和依赖，恢复时使用同一份定义。

定义使用 `schemaVersion`、`name`、`alias`、`invoke`、`steps`、`needs` 与 `approve`。草拟步骤给出提示词，发布步骤通过 `uses` 选择 Weora 现有操作。草拟提示与审批文案可引用原生会话、来源、发布选项、评分标准及冻结草稿数量。执行过程沿用成员对知识发布、会话归档和评分的独立权限。团队配置只能引用已登记的操作。

审批记录保存审批人、发起身份、审批方式及所见草稿。必需审批由已登录的人提交。可选审批按发起时选择允许发起设备说明理由并回答、由本人回答，或自动同意。拒绝会跳过依赖成功审批的发布步骤，独立的会话归档仍按发起时选项处理。会话分享步骤通过原生会话指纹及固定评分收据校验完成状态。
