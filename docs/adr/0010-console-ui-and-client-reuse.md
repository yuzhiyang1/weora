# ADR-0010：控制台组件与跨端界面复用

- 状态：组件与视觉选择已被 [ADR-0013](0013-heroui-console-ui.md) 替代；业务与跨端边界继续适用。
- 日期：2026-10-20

## 背景

控制台已有认证、Agent、Skill、项目、运行和飞书上下文能力。原组件和页面样式无法形成统一的工作台体验，继续逐页追加样式会放大维护成本。当前改造已获得重写交互和按需调整接口的授权。

## 决策

1. 使用 shadcn/ui 的 MIT 组件源码作为基础，配合 Radix、Tailwind CSS 和 Lucide。保留 React 18、React Router、TanStack Query 和 Rsbuild，避免把视觉重构扩大成运行框架升级。
2. HeroUI 仅提供视觉细节参考，不同时安装第二套组件库。Multica 仅提供公开交互流程参考，不复制其代码、CSS、图片、图标或品牌内容。Plane 不作为新界面的组件来源。
3. `apps/web/src/components/ui` 维护基础组件；`components/console` 组合按钮、表单、弹窗、列表和反馈状态；各 feature 继续拥有数据请求、权限与业务行为。
4. `styles/theme.css` 定义浅色和深色语义令牌。布局、控件、资产页面和工作台样式分别维护，避免恢复为一个大型全局样式文件。
5. 首页读取当前身份可见的真实资产与任务。当前页数量明确标为已加载数据，不冒充全量统计；读取失败不能展示为“没有待处理事项”。
6. 运行详情以概览、来源资料、工具调用、审批交付、事实记录组织内容。页签只改变内容展示，不改变事件续读、取消、审批、恢复或权限撤销行为。
7. 表单提交期间禁用重复提交及关闭入口。失败保留输入并显示错误；成功释放忙碌状态，允许同一个已挂载弹窗再次打开。弹窗使用 Radix 管理焦点，窄屏侧栏关闭时从键盘访问路径中移除。

## 跨端边界

沿用 ADR-0001。当前交付是可响应窄屏的 Web 控制台。未来桌面客户端采用 React DOM 时，可以复用页面、控件和设计令牌，文件系统、通知、窗口等能力由桌面适配器提供。当前不创建空的桌面包或移动包。

原生移动 App 优先复用数据契约、领域行为和设计令牌，按触控场景重新组织导航和控件。本次响应式页面不等同于已交付原生 App。

## 影响

- 移除 Semi UI 与 Semi Icons 依赖，页面使用同一套控件和状态样式。
- 现有后端契约满足迁移需要，本次未修改后端接口。
- 工作流、知识库和协作室仍标记为规划功能，不生成假业务数据。
- 验证命令、真实浏览器链路和截图见 `docs/development/weora-ui-refactor-acceptance-20261020.md`。
