# ADR 0016 Weora 内置 Super-agent 主 Agent 与执行会话协作

- 状态：Accepted（用户明确要求参考源码补全，并保持现有技术栈、平台架构与审批）。
- 日期：2026-11-03。
- 依据：[源码移植清单](../architecture/superagent-source-port.md)、[整体执行层方案](../architecture/execution-layer-upgrade.md)。

主 Agent 接收显式请求及经配置准入的未 @ 候选，调用结构化工具作出路由、规则评估和接单决定，分配并管理 Worker 会话。使用持续 Task、不可变接单依据、代次化执行安排和已有 Run；主会话的协调轮次与用户任务分别记录。

消息、线程、评估、决定、订阅、输入、报告、会话和副作用持久化在 PostgreSQL。通知通过现有 Redis/Celery，收到消息后立即异步唤醒，并以定时维护、租约、游标和幂等补偿。模型推理与外部调用期间不持有业务事务。

主 Agent 没有审批或研发写工具。Worker 的 Pi 会话支持持久历史和运行中输入，业务工具继续经过 Weora Gateway；未知写结果不重放。仓库、构建及代码托管来自现有项目和 CodeSource，不绑定 GitHub。

规则、模式、策略版本、来源及参与者由平台验证，未 @ 接单不等于批准写入。默认 observe；auto 须管理员显式配置规则及来源范围。旧显式入口继续可用，不同时运行两套回复和派工路径。

接受本 ADR 不代表实现或真实验收已完成；以源码清单对应的代码和实际测试为准。
